# 🔫 FPS Prototype – Game Development Course @ SUU

This repository contains a simple first-person shooter prototype created for the **Game Development course** at **Southern Utah University (SUU)**. The goal of the project was to implement basic FPS mechanics including camera control, player movement, shooting, and a simple key-door interaction.

---

## 🎮 Features

- 🧍‍♂️ **First-Person Controller**
  - Mouse-look camera system
  - Smooth player movement using Unity’s CharacterController

- 🔫 **Basic Shooting Mechanic**
  - Fire projectiles using a simple raycast or prefab bullet
  - Limited visual or gameplay feedback (prototype only)

- 🚪 **Door + Key Interaction**
  - Pick up key object
  - Unlock and open a locked door when the player has the key

---

## 🛠️ Technologies Used

- Unity Engine (URP/Standard)
- C#

---

## 📦 Project Status

This was a short-term, class project focused on learning core FPS components. It’s no longer in development, but serves as a simple reference for Unity-based FPS foundations.
